---
name: complete-backlog-tasks
description: Work through unchecked backlog tasks step by step, validate each result, and keep the task tracker accurate.
---

- Read the backlog or TODO file before changing project files.
- Identify the next unchecked task in the current phase and restate its concrete deliverable internally.
- Inspect nearby files and existing conventions before selecting an implementation path.
- Complete one task at a time and keep each edit limited to that task's scope.
- When a task creates a document, check how project documentation is discovered and add one minimal reference from the relevant index, backlog, or entry point.
- Validate the result with the cheapest relevant check, such as JSON parsing, a test, a build, or a targeted file inspection.
- Mark a task complete only after its deliverable and validation check both succeed.
- Preserve unchecked tasks and leave later phases unchanged unless the completed task requires a direct update.
- Report the files changed, the validation performed, and the next remaining task.
