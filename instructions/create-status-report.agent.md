# Weekly Status Report

Generate weekly status reports using these rules:

- Use Markdown format.
- Include these sections in order: Accomplishments, Blockers, Next Week.
- Use bullet points only; do not write prose paragraphs.
- Keep the report to a maximum of 20 lines.
- Use a professional tone.
- Avoid fluff words and filler language.
